# Marketing site

This folder is an isolated static landing-page draft for The Order of Order. It
does not alter the Vite/Phaser game build or the itch.io packaging flow.

For local review, serve this directory with any static HTTP server. The page has
no package dependencies.

## Cloudflare Workers contract

The production website is a single Cloudflare Worker with static assets. The
repository-level web build combines this landing page with the Phaser game:

- `npm run build:web` writes the deployable site to `site-dist/`.
- The marketing site is served at `/`.
- The game is built with a `/game/` Vite base and served at `/game/`.
- `wrangler.jsonc` deploys the combined directory and owns the apex domain.

Do not deploy `marketing-site/` or the root `dist/` directory by themselves; both
are inputs to the combined build.

The three doctrine cards, gameplay images, and silent WebM loops are authentic
game renders generated by the development-only Capture Studio. Regenerate stills
with `node scripts/capture-marketing.mjs` and motion with
`node scripts/capture-marketing-motion.mjs --out marketing-site/assets`.
Character and hero illustrations remain art-direction concepts.

## Character roster art

`art-src/characters/` holds the illustration masters; it is excluded from the
deployed build. `npm run art:characters` re-exports each master as the three
WebP widths the roster's `srcset` asks for, named `<stem>-<width>.webp`.

Masters must be **square** and at least **1200px** on a side (2400px preferred).
The roster renders at `aspect-ratio: 1 / 1` with `object-fit: cover`, so an
off-ratio master is centre-cropped rather than letterboxed.

The grid stays three columns at every breakpoint, so the image never renders
wider than **371 CSS px** — the width it reaches once the container caps at
1180px, and holds at from 1216px up. That is 742 device pixels at 2x and 1113 at
3x, which the 1200w variant covers. Note that `.character-roster` sets
`grid-template-columns` twice inside the same `@media (max-width: 820px)` block;
the later rule wins, so the earlier single-column declaration has no effect.

The files currently in `assets/` are placeholders upscaled from the old 480x640
concepts — the only reason `--allow-upscale` exists. Real masters will not need
that flag; if the script asks for it, the delivery is too small.

The canonical and Open Graph metadata target `https://the-order-of-order.com/`.

## Ornament

`js/` holds the page's decoration — turning sigils, drifting motes, and the
motions that carry them. Hand-written browser modules, no bundler, no
dependencies; the `_headers` CSP allows them because they are same-origin.

- `boot.js` — the only synchronous script. Puts `has-js` and `js-motion` on the
  root element before the first paint, so nothing appears and then hides itself.
- `sigil.js` — the game's ambient sigils redrawn as SVG. A direct port of
  `buildSigil` / `buildSigilRing` in `src/art/textures.ts`: same radii, tick
  cadences, gate counts, and per-stroke alphas. **If a variant changes in the
  game, change it here too.** Fills `[data-sigil]` slots; add `data-sigil-ring`
  for the counter-turning band.
- `motes.js` — one additive canvas per `[data-motes]` slot, the landing-page
  cousin of `AmbientLayer`'s mote field. Each field parks itself when its
  section leaves the viewport or the tab is hidden.
- `flourish.js` — arrival on scroll (`[data-reveal]`, grouped and staggered by
  `[data-reveal-group]`), background lag (`[data-parallax]`), the run-fact
  counters (`[data-countup]`), pointer tilt (`[data-tilt]`), the hero's pointer
  light, the header's scroll progress rule, and the header die's roll on hover
  (another whole turn, with the face cycling while it turns).

None of it is load-bearing. Every animated rule in `styles.css` is gated on
`html.js-motion`, so a visitor without scripting — or one who has asked for
reduced motion — gets the same finished page with nothing hidden behind an
animation that will never run. When adding ornament, keep that gate: an element
that starts at `opacity: 0` must only do so under `.js-motion`.
